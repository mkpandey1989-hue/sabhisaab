Aksar pooche jaane wale sawaal

Rate 'se' kyun likha hai?

Har kaam alag hota hai. Likha hua rate shuruaati hai. Aapka kaam dekh kar likhit quote milta hai jisme version number hota hai (jaise SH261123AB-v1). Sirf wahi likhit quote pakka maana jaata hai, baad mein rakam nahi badhti.

Advance kitna dena hota hai?

₹10 se ₹199 wale chhote kaam par poora payment pehle. Baaki kaam par lagbhag 30% advance, phir demo dekh kar baaki. Final file, code aur account poora payment hone ke baad milta hai.

Code aur account kiske naam hoga?

Aapke naam. Website, domain, hosting, payment gateway, bot - sab aapke apne account par banta hai. Hum aapka password nahi lete; zaroorat ho to aap access dete hain aur kaam ke baad hata dete hain.

Care plan band karna ho to?

Care plan har mahine ka hai, kabhi bhi band kar sakte hain. Charge sirf tab tak lagta hai jab tak service chal rahi hai. Hum kabhi service band karein to 30 din pehle batayenge aur saara code aur access aapko de denge.

Trading bot banate ho?

Sirf aapki apni strategy ka code - backtest, indicator, alert, paper-trading aur bot jo aapke apne broker account, static IP aur server par aap khud chalate hain (SEBI ka algo niyam). Hum tip, signal ya profit ka vaada nahi dete aur kisi ka account nahi chalate.

Online form bharne mein madad kaise hoti hai?

Aap apni jaankari aur document khud dete hain; hum form bharne mein madad karte hain (screen-share ya aapke saamne). OTP aur password sirf aap daalte hain - hum kabhi nahi maangte. Portal ki sarkari fees aap seedha portal par bharte hain; hamara charge sirf madad ka hai. Hum sarkari agent nahi hain, aur aapke document apne paas nahi rakhte.

Kaun sa kaam nahi lete?

Data scraping, kisi ka phone/email nikalna, bulk ya spam message, nakli review/followers, hacking, kisi ki site ki copy, betting aur loan app. Ye kanoon aur platform niyam ke khilaf hain.

Referral code kaise chalta hai?

Form bhejne par aapko ek REF code milta hai. Dost us code se kaam karwaye to dost ko pehle kaam par 10% chhoot milti hai, aur dost ke chukaye bill ka 10% aapko bonus milta hai (₹300 se bade bill par, ek baar mein max ₹500). Bonus dost ka payment hone ke 7 din baad pakka hota hai, agle paid kaam ke bill ka max 10% kaat sakta hai aur 90 din tak chalta hai. Ek hi phone/device se apna hi code nahi chalta, aur bonus nakad nahi milta.

⚠️ Trading tool sirf aapki apni strategy ka code hai — hum SEBI-registered advisor nahi, koi tip/signal/profit ka vaada nahi. Bot aapke apne account/server par aap chalate hain. Ye page aam jaankari hai; tax/kanooni faisle ke liye CA/vakil se salah lein.
